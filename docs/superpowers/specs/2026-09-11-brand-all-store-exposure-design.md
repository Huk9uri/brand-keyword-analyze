# 한촌 전체 매장 키워드 노출 집계 설계

## 승인된 범위
전체 한촌설렁탕 매장을 자동 조회하여 검토된 후보의 검색량, 매장별 일반 순위, TOP10·TOP20 노출률을 보고한다. 후보 자동 선정과 추천은 포함하지 않는다. 기존 5개 설정 실행과 오프라인 재현은 유지한다.

## 입력과 모집단
- `--all-stores`로 전체 매장 모드를 선택한다. 기존 후보 설정의 7개 키워드와 매출 기간을 사용한다.
- ERP의 한촌 운영 매장(법인 01, 브랜드 001, 유형 001, 운영 002, 폐점일 없음)을 매장 코드별로 조회하고 매장 뷰 및 좌표 캐시를 LEFT JOIN한다. Place ID·SMARTPLACE_ID 누락으로 모집단을 줄이지 않는다.
- 설정에 존재하는 매장은 기존 target_store_id와 검증 좌표를 재사용한다. 나머지는 매장 코드 기반 ID를 사용한다.
- 공개 ID 없음, ID 충돌, 중복 매핑, 좌표 없음·오류를 구분한다. 동일 Place ID를 여러 ERP 매장이 공유하면 조사에서 제외하고 사유를 남긴다.
- 보고서 입력에 전체 매장 명단과 조회 시각을 고정한다. 재현 과정에서 DB를 다시 조회하지 않는다.

## 조회 및 수집
기본 실행은 읽기 전용이다. 수집 플래그가 있으면 ID가 검증된 매장의 누락 좌표를 기존 확인기로 보강한다. 좌표 확인 실패를 숨기지 않는다. 순위 작업은 1~100건의 배치로 나누며 배치별 계획·수집 결과를 보존한다. 보안 확인·중단·저장 실패 시 다음 배치를 실행하지 않는다. 재실행 시 DB의 유효 결과를 다시 읽어 성공 작업을 재사용한다. 기존 출력 폴더는 덮어쓰지 않고 새 폴더로 재실행한다.

전체 순위 조회는 매장×검색어를 작은 묶음으로 조회하고, 최신 스냅샷의 카드도 묶음 조회한다. 오래된 성공으로 최신 실패를 덮지 않는다. 조회 조건에 프로필, 좌표, 모바일, 기준 시각을 포함한다.

## 지표
- 전체 매장, ID 확인 매장, 좌표 확인·조사 가능 매장, 키워드별 유효·미조사·부분·실패·오래된 관측 수를 표시한다.
- TOP10·TOP20 노출률 = 해당 범위의 자사 일반 순위 확인 매장 / 유효 관측 매장. 분모 0은 null/산정 불가다.
- 전체 매장 중 확인된 노출 비율과 관측 커버리지도 별도로 표시한다. 미확인 매장을 비노출로 추정하지 않는다.
- 순위 분포는 1~3, 4~10, 11~20, 유효한 TOP20 미노출, 미확인으로 구분한다. 평균·중앙값은 TOP20에 관측된 순위만 사용한다.
- 검색량은 키워드당 검색광고 제공 기간의 전국 PC·모바일·합계 또는 구간이다. 매장 수를 곱하거나 매장별 지역 검색량이라고 표시하지 않는다. 오래된 값과 실패·없음은 0이 아니다.
- `report.md`, `comparison.json`, `keyword-summary.csv`, `store-ranks.csv`, `store-inventory.csv`를 만든다. CSV의 사용자 문자열은 수식으로 실행되지 않도록 이스케이프한다.

## 검증
기존 23개 테스트를 유지하며 100건 초과 입력, ID·좌표 누락과 중복, 모집단 분모, 부분·오래된 순위, 검색량 중복 합산 방지, 무대상 보고서, 배치 중단·재사용, CSV·오프라인 재현을 검증한다. 실제 DB 읽기 전용 실행으로 매장 명단과 보고서 생성까지 확인한다. 전체 외부 수집은 구현 검증의 필수 조건으로 삼지 않는다.
