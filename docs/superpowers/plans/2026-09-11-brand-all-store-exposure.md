# 전체 매장 키워드 노출 집계 구현 계획

목표: 승인된 전체 매장 조회·순위·검색량 집계 기능을 기존 반복 조사 CLI에 통합한다.

1. `all_stores.py`와 테스트: ERP 기반 모집단, ID 중복·누락 분류, 좌표 및 기존 설정 재사용을 순수 함수로 구현한다. 좌표가 없는 매장은 목록에 보존한다.
2. `core.py`와 `summary.py`: 전체 모드의 100건 제한을 배치 제한으로 전환한다. 후보 지표를 매장 행과 분리하고, 유효 관측 분모와 전체 커버리지·순위 분포를 독립적으로 계산한다. 0개 조사 가능 매장도 보고한다.
3. `repository.py`: 전체 매장 모드 조회 및 누락 좌표 확인, 최신 순위 묶음 조회를 구현한다. SQL 파라미터와 원천 증적을 보존한다.
4. `batch_collection.py`: 순위 계획을 최대 100건씩 나누고, 수집 결과를 배치별 보존하며 중단·저장 실패를 전파한다. 새 실행에서 유효 DB 자료 재사용을 검증한다.
5. `cli.py`: `--all-stores`, `--batch-size`를 추가하고 모집단을 최초에 고정한다. 기존 실행과 재현 흐름을 유지하고 CSV·보고서 출력을 연결한다.
6. 실패하는 테스트를 먼저 확인한 뒤 최소 코드를 구현한다. 전체 tests 실행, 실제 DB 읽기 전용 보고서와 replay 동일성 확인, 코드 리뷰 후 사용법과 검증 결과를 기록한다.

개발 브랜치: `codex/brand-all-store-exposure`. 이번 요청은 구현이며 전체 매장 외부 순위 수집은 자동 시작하지 않는다.
