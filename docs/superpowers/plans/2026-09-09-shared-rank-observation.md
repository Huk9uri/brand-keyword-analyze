# 메뉴별 공유 순위 관측 구현 계획

목표: 좌표 없는 동일 검색어의 수집을 메뉴당 1회로 줄이고 각 매장 후보의 평가 참조를 보존한다.

설계: 기존 순위 DB 스키마와 매장별 관측은 유지한다. 대표 작업으로 저장한 실제 스냅샷과
매장별 후보를 연결하는 명시적 매핑을 실행 영수증에 기록한다. 원천 재수출 시 실행 ID,
작업 키, 검색어, 기기, 프로필 및 후보·매장 식별을 검사하고 공유 참조를 동결한다.
과거 관측을 이름만으로 공유하거나 복제하지 않는다.

- [x] 중복 수집 감소, 5개 매장 연결, 잘못된 매핑 거절 테스트를 먼저 실행한다.
- [x] 수집 계획·영수증과 원천 재수출·평가 연결을 구현한다.
- [x] 기존 관측, 최신 실패, PARTIAL, 시간대 및 회귀 테스트를 검증한다.
- [x] 메뉴 1건을 재시도 없이 실제 UC 통합검색에서 확인하고 증거를 보존한다.
- [x] 결과가 완전할 때만 확대 수집한다. 이번 결과는 PARTIAL이므로 확대하지 않았다.

최종 대표키워드 선정과 경쟁점 규칙의 자동 승격은 이번 변경 범위에 포함하지 않는다.
