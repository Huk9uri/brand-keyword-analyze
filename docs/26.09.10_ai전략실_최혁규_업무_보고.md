# 26.09.10 AI 전략실 최혁규 업무 보고

## 1. 금일 업무 종합 개요

한촌설렁탕 5개 매장을 대상으로 범용 키워드의 1차 조사를 완료하고, 지역명·식사 목적을 활용한 신규 유입 키워드 발굴을 진행했습니다. 검색량, 매장 좌표 기준 자사 순위, 노출 경쟁점 자료를 수집하고 DB 적재 결과를 검증했습니다.

또한 네이버 스마트플레이스의 실제 유입 검색어 데이터를 확인하여, 기존 유입 경로와 신규 시험 후보를 구분할 기초 자료를 확보했습니다. 다만 매장별 수집 기간과 누락 상태가 달라, 최종 추천에 앞서 유입 데이터 수집 안정성을 확보하는 것을 우선 과제로 정리했습니다.

- 범용 키워드: 매장별 16개씩 총 80건의 검색량·순위 조사 및 경쟁점 keywordList 연결 완료
- 신규 유입 후보: 지역명 조합·혼밥 등으로 확대 조사 진행
- 실제 유입 분석: 4개 매장의 이력 확보 및 현재 자료의 한계 확인
- 최종 등록 키워드: 매장당 총 5개 선정은 미확정이며 실제 등록 변경은 수행하지 않음

## 2. 프로젝트 진행 현황

| 구분 | 금일 상태 | 핵심 결과 |
|---|---|---|
| 범용 키워드 1차 조사 | 완료 | 5개 매장 × 16개, 총 80건의 검색량·순위 확인 |
| 범용 후보의 경쟁점 자료 | 완료 | 노출 경쟁점 331곳의 유효 keywordList 자료 연결 |
| 지역형 키워드 | 추가 조사 진행 | 지역 조합 72건 검색량 확인, 그중 56건 순위 조사 |
| 혼밥 관련 키워드 | 1차 조사 완료 | 5개 매장 일반형·지역형 총 10건 순위 조사 |
| 직장인 점심 등 기타 목적형 | 검토 중 | 일부 원문 근거 확인, 추가 조사 필요 |
| 실제 유입 검색어 | 기초 분석 완료 | 4개 매장 이력 확보, 최신성·누락 문제 확인 |
| 유입 수집 안정화 | 후속 과제 | 매장 매핑·스케줄·실패 이력 확인 필요 |
| 매장별 최종 5개 선정 | 보류 | 안정적인 기존 유입 자료 확보 후 통합 판단 |

※ 범용 키워드 완료는 선정한 16개 표현에 대한 1차 조사 완료를 의미합니다. 모든 범용 후보의 적합성 검토나 최종 추천 확정을 의미하지 않습니다.

## 3. 범용 키워드 조사 및 경쟁점 분석

부천본점·강동점·천안쌍용점·선릉역점·신림역점을 대상으로 설렁탕, 갈비탕, 도가니탕, 국밥, 한식 등 메뉴·일반 표현의 검색량과 실제 노출을 확인했습니다.

기존 순위 25건을 재사용하고 55건을 추가 수집하여 총 80건의 유효한 순위 자료를 확보했습니다. 자사 상위 20개 내 노출은 54건, 미노출은 26건이었습니다.

해당 후보의 노출 경쟁점 331곳에 keywordList 자료를 연결했습니다. 금일 부족한 142곳을 추가 수집했으며, 키워드 확보 118곳·빈 목록 24곳·실패 0곳이었습니다. 빈 목록도 수집 결과로 구분해 보존했습니다.

검색 결과에 노출된 타 브랜드 매장은 업종·메뉴 일치 여부와 관계없이 검색 경쟁점으로 다뤘습니다. 경쟁점 keywordList와 후보의 일치율은 참고 자료이며, 일치율이 낮다는 이유로 경쟁이 약하거나 성과가 좋다고 판단하지 않았습니다.

## 4. 지역형·신규 유입 후보 확대 조사

사용자가 제공한 엑셀의 「AI 전략실 전달 키워드」 시트와 추가 상권 자료를 활용해 지역 조합을 구성했습니다. 강동점은 진황도로 110의 기존 매장이며 강동명일점과 별도로 구분했습니다.

| 조사 구분 | 검색량 확인 | 순위 조사 | 정상 | 부분 수집 |
|---|---:|---:|---:|---:|
| 천안·선릉·신림 지역 + 메뉴 | 40개 조합 | 24건 | 21건 | 3건 |
| 부천·강동 지역 + 메뉴 및 5개 매장 혼밥 | 지역형 32개 + 혼밥 검색어 6개 | 42건 | 31건 | 11건 |

혼밥 일반 검색어는 매장 간 검색량을 공유하므로, 검색량 조회 개수와 매장별 순위 조사 건수는 다릅니다. 지역형 72개 중 순위 미조사 16개는 탈락 후보가 아니라 조사 대기 후보입니다.

순위 조회는 UC·독립 임시 프로필·Selenium을 사용하고, 검색 URL에 자사 매장의 경도·위도를 적용했습니다. 좌표는 검색 기준 위치로만 사용하며 거리 자체는 점수에 넣지 않았습니다. keywordList는 기존 모바일 매장 페이지 수집 경로를 유지했습니다.

### 혼밥 후보의 확인 결과

| 검색어 | 월간 PC·모바일 합산 검색량 |
|---|---:|
| 혼밥 | 9,350 |
| 선릉역혼밥 | 1,350 |
| 신림역혼밥 | 890 |
| 길동역혼밥 | 90 |
| 쌍용동혼밥 | 40~49 구간 |
| 중동역혼밥 | 20~29 구간 |

혼밥 관련 10건 중 정상 수집된 8건은 모두 자사가 상위 20개에 없었습니다. 중동역혼밥·쌍용동혼밥 2건은 부분 수집으로 노출 여부 판단을 보류했습니다.

검색 수요는 확인했지만 등록 후 노출 개선은 검증하지 못했습니다. 따라서 혼밥은 현재 성과가 확인된 추천이 아니라 **신규 유입을 시험할 후보**로 유지했습니다. 저검색량 또는 자사 미노출만으로 후보를 제외하지 않았습니다.

## 5. 후보 근거 검토 및 추천 방향 정리

기존 3,850개 후보를 보존하면서 지역·이용 목적 후보를 합친 3,926개 조사 목록을 작성했습니다. 이는 당시 통합 목록의 행 수이며, 이후 별도 실행에서 조사한 추가 조합까지 모두 반영한 최종 후보 수는 아닙니다.

리뷰 문맥 검토에서는 혼밥 이용 경험·자리 설명을 확인했습니다. 반면 ‘빠른 점심’ 후보에 저녁 방문 후기가 연결된 사례, 회식 표현에 다른 층의 서비스나 해시태그가 포함된 사례도 확인했습니다. 단순 단어 추출만으로 매장 적합성을 승인하지 않도록 구분했습니다.

최종 선정은 범용형·지역형·이용 목적형을 합쳐 매장당 총 5개로 구성합니다. 기존 초안은 검토용으로 남기며, 다음 두 역할을 구분해 판단하기로 했습니다.

- **기존 유입 확대:** 이미 유입되는 검색어의 노출과 방문을 늘리는 후보
- **신규 경로 시험:** 기존 자료에서 관측되지 않은 검색어 중 관련성과 수요가 있는 후보

브랜드명에 설렁탕이 포함되어 있다는 사실만으로 해당 등록 키워드의 효율이 낮다고 확정하지 않았습니다. 등록 슬롯의 추가 효과와 실제 유입 변화는 별도 검증이 필요합니다.

## 6. 실제 유입 검색어 데이터 확인

naverDB의 `smartplace_keyword_all`을 조회하여 네이버 스마트플레이스가 집계한 유입 검색어 이력을 확보했습니다. 이 테이블의 관리 ID는 공개 Place ID와 달라 매장명을 기준으로 연결했으며, 부천·강동은 수집 코드의 계정 설정도 확인했습니다.

| 매장 | 최신 데이터 | 확인된 기존 유입 예시 | 확인 사항 |
|---|---|---|---|
| 부천본점 | 2026-09-06 | 한촌설렁탕, 한촌설렁탕본점, 부천한촌갈비 | 최신 날짜까지 28일 중 14일 기록 |
| 강동점 | 2026-09-06 | 설렁탕, 길동맛집, 갈비탕 | 최신 날짜까지 28일 중 14일 기록 |
| 천안쌍용점 | 미확인 | 해당 매장 데이터 연결 필요 | 관리 ID·수집 대상 확인 필요 |
| 선릉역점 | 2026-04-19 | 선릉설렁탕, 선릉역설렁탕 | 최신 자료 부족, 과거 참고용 |
| 신림역점 | 2026-08-23 | 신림역설렁탕, 삼계탕 | 최근 자료 보강 필요 |

부천·강동의 기록 공백은 수집 누락인지 운영 일정 때문인지 아직 확인하지 않았습니다. 매장별 최신 날짜가 달라 현재 요약은 동일 기간 비교가 아닙니다.

저장값은 일별 비율이며 대부분 순위 1~5위 목록입니다. 목록에 없다는 이유로 유입 0 또는 완전히 새로운 경로라고 단정하지 않았습니다. 비율을 합산해 기간 전체 비중으로 쓰거나 방문 횟수로 환산하지 않았습니다.

원본 3,122행을 점검해 형식 이상 1행을 분석에서 격리하고 중복 1행을 정리했습니다. ‘검색어 없음’ 표시는 실제 검색어와 분리했으며 원본 DB는 수정하지 않았습니다.

| 지역형·혼밥 후속 순위 | 42개 스냅샷·805개 결과 행 DB 재조회 검증 |

부분 수집은 결과 목록의 끝을 확인하지 못한 상태로 보존했습니다. 데이터가 저장됐다는 사실과 정상적인 순위 판단이 가능하다는 사실을 구분했습니다.

## 8. 미완료 작업 및 확인 필요 사항

- 매장별 실제 유입 데이터의 누락·지연 원인 확인
- 천안쌍용점 스마트플레이스 관리 ID 및 수집 대상 설정 확인
- 선릉역점 등 최신 유입 자료 보강
- 직장인 점심, 기타 이용 목적·서비스·음식 특성 후보의 근거 검토
- 신규 지역형·혼밥 검색 결과에서 추가된 경쟁점의 keywordList 보강
- 지역형 순위 미조사 16건 및 부분 수집 결과의 후속 처리
- 기존·추가 후보와 실제 유입 이력을 합친 목록 갱신
- 비교 가능한 유입 기간 확보 후 매장별 최종 5개 및 선정 이유 작성

## 9. 차일 업무 계획

1. **수집 대상 정합성 확인:** 스마트플레이스 관리 ID와 공개 Place ID, 매장명을 연결하고 대상 누락 여부를 확인합니다.
2. **수집 안정성 점검:** 날짜별 실행·실패·미실행·유입 없음 상태를 구분하고 스케줄 및 저장 과정의 원인을 확인합니다.
3. **자료 보강:** 가능한 누락 기간을 재수집하고 중복·날짜·저장값을 검증합니다.
4. **추천 기준 재적용:** 안정적으로 확보한 기존 유입 이력을 바탕으로 기존 경로 확대 후보와 신규 경로 시험 후보를 나눕니다.
5. **통합 추천 준비:** 매장당 총 5개의 선정 근거와 적용 전후 유입 확인 방법을 정리합니다.
