# Chrome 종료·임시 프로필 잠금 보완

## 확인한 원인

매장 좌표가 바뀔 때 기존 브라우저를 닫는다. 이전 코드는 종료 핸들의 5초 대기 결과가 시간 초과여도 경고만 기록하고 프로필을 삭제했다. 삭제 재시도까지 실패하면 OSError가 배치 전체를 중단했다.

## 변경

- 종료 전 확보한 Windows 프로세스 핸들에 종료 권한을 포함한다.
- 정상 종료를 5초 기다린 뒤 시간 초과이면 해당 핸들로 TerminateProcess를 호출하고 다시 5초 기다린다. PID 재조회나 전체 Chrome 종료 명령은 사용하지 않는다.
- 종료 확인 실패는 OSError로 전달하고 세션 종료 경로의 프로필 삭제를 생략한다.
- 종료 후에도 잠긴 프로필은 객체를 보존하여 다음 세션 종료·생성 시점에 다시 정리한다. 대기 한도는 프로세스당 3개이며 한도에 도달하면 새 브라우저를 만들지 않는다.
- 경고 로그에 PID, 프로필 경로, 지연 정리 개수를 남긴다.
- 요청 간격 15초와 수집 결과 판정·DB 저장은 변경하지 않는다.

## 검증과 한계

관련 테스트 101개 통과. Windows 실제 Chrome에서 로컬 data 페이지를 사용하는 5회 생성·종료 및 프로필 삭제를 확인한다.

프로세스 핸들은 드라이버가 관리하는 브라우저 PID에 대해서만 확보한다. 임의의 자식 프로세스나 파일 잠금 소유자를 검색해 종료하지 않는다. 브라우저 종료 뒤 외부 프로세스가 잠금을 유지하는 경우에는 지연 정리 한도로 중단될 수 있다. 지연 목록은 현재 수집 프로세스 메모리에 있으므로 프로세스 종료 후에는 경고 로그의 경로가 잔여 프로필 확인 근거다. 이번 변경은 과거 실행의 임시 폴더를 일괄 삭제하지 않는다.
