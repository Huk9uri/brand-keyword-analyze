# 수집 운영 검증·LLM 요약·메일·정기 실행 연결 계획

사용자가 네 작업의 진행을 승인했다. 모델은 최신 여부가 아니라 토큰·비용·특성·실제 품질 평가로 선정한다. 수신 주소·발신 서비스·실행 일정은 사용자 확인 전 임의로 정하지 않는다.

1. 실제 통합 수집을 실행하고 실패가 발견되면 재현 테스트 후 수정한다. 정상 수집 DB는 재사용한다.
2. 집계·판정은 코드가 수행한다. LLM 입력은 키워드별 집계·대표 후보·변화·품질로 제한하며 원본 POS 전체는 보내지 않는다. JSON Schema로 요약을 받고 근거 ID와 인용 사실을 코드로 대조한다. 사용 토큰·응답 ID·모델을 기록한다.
3. 결과 폴더에서 요약 작성·메일 준비·발송을 별도 재실행할 수 있게 한다. 발송 전 미리보기 `.eml`을 저장한다. 동일 결과/수신자/내용은 재발송하지 않으며 SMTP 수락 여부 불명확 시 자동 재전송하지 않는다. 수락은 수신함 도착과 구분한다.
4. 수집·요약·발송을 연결하는 실행 명령과 실행 기록을 만든다. 사용자 일정·발신 설정 확인 후 정기 실행을 등록하고 실제 전달을 확인한다. 수집 실패 또는 요약 검증 실패를 성공 메일로 전송하지 않는다.

## 모델 비교 원칙

- 후보: GPT-4.1 mini(비추론 요약 기준선), GPT-5 mini(추론형 비교군), GPT-5.6 Luna(저비용·추론 끄기 가능 비교군).
- 같은 입력에서 사실/보류 상태 보존, 근거 일치, 과장 금지, 한국어 가독성, 지연, 실제 입력·출력·추론 토큰을 비교한다.
- 정확성 기준을 충족한 모델 중 실측 비용이 낮은 것을 선택한다. 키 미설정 상태에서는 품질 실측 완료나 최종 모델 선정으로 보고하지 않는다.
- 공식 자료: https://developers.openai.com/api/docs/models/gpt-4.1-mini , https://developers.openai.com/api/docs/models/gpt-5-mini , https://developers.openai.com/api/docs/models/gpt-5.6-luna , https://developers.openai.com/api/docs/guides/structured-outputs
- 2026-09-16 확인 기준 100만 토큰당 입력/출력 USD: 4.1 mini 0.40/1.60, 5 mini 0.25/2.00, 5.6 Luna 0.20/1.20. 캐시 할인·Batch 할인·세금은 추정에 포함하지 않는다. 추론 토큰은 실제 API 사용량으로 반영한다.
