# Chrome 임시 프로필 정리 보완

## 문제와 원인

`uc_keyword_rank_*`는 수집기가 만든 Chrome 임시 프로필이다. 기존 코드는
Chrome 종료 요청 직후 한 번만 삭제했고, 수집기가 종료 예외를 무시했다.
Windows 파일 잠금이 남으면 프로필이 누적될 수 있었다.
2026-09-14 수집 DB에는 `No space left on device` 오류가 확인됐다.

## 구현

- Windows에서는 종료 요청 전에 소유 Chrome 프로세스의 동기화 핸들을 열고,
  종료 요청 후 최대 5초 기다린다. 핸들은 항상 닫는다.
- 임시 프로필 삭제는 0.5초 간격으로 최대 6회 시도한다.
- 최종 실패는 경로와 예외를 로그에 남기며, 정상 세션 종료 중 발생한 파일
  시스템 오류는 수집기로 전파해 새 프로필의 연속 생성을 막는다.
- 브라우저 초기화 실패 경로에도 같은 종료 대기와 삭제 재시도를 적용한다.
  초기화 오류 자체는 유지하고 정리 오류는 로그에 별도로 남긴다.
- 기존 결과 및 다른 앱의 프로필을 삭제하거나 다른 Chrome을 종료하지 않는다.

## 검증 및 재시작

잠금 후 삭제 성공, 재시도 소진 시 경로 로그, 초기화 실패 시 삭제 재시도,
정리 실패 시 수집 중단 회귀 테스트를 추가했다.
실제 Chrome 반복 종료에서 프로필 삭제를 확인한 뒤 기존 DB 유효 관측을
재사용하여 별도 출력 경로에서 전체 매장 수집을 재개한다.
강제 프로세스 종료나 시스템 종료까지 자동 삭제를 보장하지는 않는다.

검증 결과: 관련 테스트 90개 통과. 실제 headless Chrome을 3회 생성해 로컬
테스트 페이지를 연 뒤 종료했으며, 세 프로필 모두 삭제됨을 확인했다.
2026-09-14 10:48 KST에 `outputs/hanchon-expanded-ranks-20260914-resume3`로
재시작했다. stdout/stderr 로그는 해당 경로에 `.stdout.log`, `.stderr.log`를
붙인 파일에 저장한다. 매출 기간은 기존과 동일한 2026-08-01 이상,
2026-09-01 미만이며 배치 크기는 50건이다.
