# 검색 노출 경쟁점 기준과 평가 변경

## 사용자 확정 기준

매장 좌표·검색어 기준 자연순위 상위 10개에서 자사를 제외한 모든 매장을
**검색 노출 경쟁점**으로 판단한다. 업종이나 실제 메뉴 판매 증거는 이 분류의 조건이 아니다.
광고는 별도로 집계한다. 자사 판별은 승인된 Place ID 목록을 사용한다.

## 평가 변경

`knowledge.competitor_basis=SEARCH_EXPOSURE` 및 별도 규칙 버전으로 새 입력을 동결한다.
이 기준에서는 기존 업종 분류를 사용하지 않는다. 자사 순위와 검색 노출 경쟁점 수,
keywordList 완전 일치·동의어 일치 비율·수집 완전성을 근거로 남긴다.

노출된 타사를 모두 경쟁점으로 정의하므로 기존 직접 경쟁점 비율은 경쟁 강도 판정에 사용하지 않는다.
해당 점수는 NULL로 유지한다. 새 빈집·경쟁 임계치는 아직 교정하지 않았으므로 근거가 모두 갖춰져도
`COMPETITION_CALIBRATION_REQUIRED`로 검토필요를 유지한다. 사람 검토표에 검색 노출 경쟁점 수를 추가했다.
과거 CATEGORY 기준 입력의 오프라인 재현은 유지한다.

## 수집 및 저장

초기 고유 대상 174곳 중 기존 keywordList 16곳은 재사용 가능했고 158곳은 신규 수집 대상이었다.
기존 keywordList 브라우저·URL 경로는 변경하지 않는다.

첫 대상에서 keywordList 5개를 정상 수집했으나 SQL Server 오류 334로 저장이 실패했다.
활성 트리거가 있는 테이블에 OUTPUT 없이 INSERT하고 같은 SQL 범위의 SCOPE_IDENTITY()로
생성 ID를 받아오도록 수정했다. 트리거와 DB 스키마는 변경하지 않았다.
보존한 첫 관측을 재수집 없이 재적재해 스냅샷 92번으로 검증했다.

원천 시간대는 실행별 +00:00을 기록하며, 기존 실행의 시간대는 그대로 보존한다.
EMPTY는 명시적인 빈 목록이며 실패·미확보를 빈 목록으로 바꾸지 않는다.
