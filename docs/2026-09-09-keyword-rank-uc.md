# 검색어 순위 수집 브라우저 변경

검색어 순위 수집의 기본 드라이버를 undetected-chromedriver(uc)로 변경했다.
참고한 `smartplace_browser.py`의 `create_uc_driver()`처럼 uc 옵션과
`user_data_dir`, `use_subprocess=True`를 사용한다. 탐색과 DOM 수집은 기존
Selenium 코드를 유지한다.

## 프로필과 실행 방식

- 세션을 생성할 때 시스템 임시 폴더에 `uc_keyword_rank_` 접두사의 고유 프로필을 만든다.
- 세션 내 검색에서는 프로필을 재사용한다. 새 세션과 재시도용 대체 세션은 새 프로필을 사용한다.
- 개인 Chrome, 스마트플레이스, 방문자 리뷰, 블로그 리뷰의 프로필을 공유하지 않는다.
- 디버깅 포트는 uc가 자동 배정한다(`port=0`). 참고 스크립트의 고정 포트와 공유하지 않는다.
- 세션 종료 시 드라이버를 종료한 뒤 프로필을 정리한다. 생성 후 초기 설정 실패 시에도 정리한다.
- 기존 모바일 사용자 에이전트, PC 화면 크기, 위치 지정, headless 설정을 유지한다.
- 실제 실행 파일의 Chrome 버전을 읽어 `version_main`에 전달한다. 최초 검증에서 Chrome 152에
  uc 기본 다운로드 드라이버 153이 선택되는 불일치를 확인하여 보완했다. 특정 버전을 고정하지 않는다.
- 초기 생성 실패 시 프로필 파일이 잠겨 있으면 경고를 남기고 원래 브라우저 오류를 보존한다.

## 설치와 검증

`requirements-keyword-discovery.txt`를 다시 설치해야 한다. Python 3.12에서
uc 3.5.5가 사용하는 distutils를 제공하도록 `setuptools>=65,<82`를 포함했다.
최초 실제 실행에는 Chrome과 uc 드라이버 다운로드를 위한 네트워크 접근이 필요하다.

자동 테스트는 프로필 간 데이터 격리, 정상 종료와 실패 시 정리, uc 생성 옵션,
기존 검색 및 수집 흐름을 검증한다. 실제 네이버 접속 성공이나 순위 정확성을
자동 테스트만으로 보장하지는 않는다.
