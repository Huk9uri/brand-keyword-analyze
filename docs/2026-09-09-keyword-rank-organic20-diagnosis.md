# 자연순위 20위 수집 보완 및 실패 원인 조사

## 확인 결과

- 기존 실행 `f722e19d-cfbc-487b-a2b5-a9f4884b03b3`의 메뉴 5건은 모두 `LOAD_TIMEOUT`이었다.
- 실패 HTML에는 이미 플레이스 카드가 있었으나, `detect_page_state`가 화면의 `위치 정보 없음` 문구를 먼저 검사하여 `LOCATION_PENDING`을 반환했다. 좌표를 설정하지 않는 평가 수집이 불필요하게 위치 확인을 기다린 것이 직접 원인이다.
- 기존 중단 기준은 광고 포함 카드 20개였고, 결과 검증도 20개 카드까지만 보존했다. 따라서 자연순위 20위를 보장하지 못했다.
- 기존 ‘펼쳐서 더보기’ 버튼 소멸 및 카드 수 안정화를 결과 끝으로 추정하는 방식은 깊이 검증에 충분하지 않았다.

## 변경한 계약

- 평가 수집 프로필: `MOBILE_NO_LOCATION_ORGANIC20_V2`. 과거 `MOBILE_NO_LOCATION_V1` 성공 기록은 새 프로필의 정상 결과로 재사용하지 않는다. 과거 입력 및 결과 파일은 변경하지 않는다.
- 평가 수집의 `requested_result_limit=20`은 자연순위 목표를 의미한다. 프로필을 기록한 `location_name` 및 실행 영수증의 `result_limit_basis=ORGANIC`으로 기존 카드 기준 실행과 구분한다.
- 브라우저와 결과 검증기에 `organic_limit=True`를 전달한다. 기존 일반 순위 CLI의 기본 카드 기준 동작은 유지한다.
- 광고는 자연순위 목표 수에 포함하지 않는다. 자연순위 20번째 매장까지의 원본 카드 순서를 보존하므로 저장 카드 수는 20개를 초과할 수 있다.
- 좌표를 설정한 세션에만 위치 확인 대기를 적용한다. 평가 세션에는 좌표를 전달하지 않는다.
- 자연순위 20개 미만이고 명시적 끝 표시가 없으면, 제한 시간까지 확장을 시도한 뒤 관측된 결과를 `PARTIAL`로 남긴다. 버튼 소멸이나 카드 수 정체만으로 끝을 확정하지 않는다.
- 실제 결과 끝이 확인되면 20개 미만이어도 완전한 짧은 목록으로 저장할 수 있다. 관측 깊이는 실제 개수 그대로 보존한다.
- 자사 매장이 상위에 발견됐더라도 20개 미만의 비종결 기록은 재수집 대상이다.
- 자연순위 연속성·광고의 자연순위 없음·필수 필드·파싱 누락 검증은 유지한다. 실패와 `PARTIAL`은 평가에서 검토필요이며 미노출 또는 경쟁점 0개로 간주하지 않는다.

## 회귀 검증 범위

- 광고 2개가 포함된 카드 20개에서 멈추지 않고 카드 22개까지 진행하는 브라우저 동작.
- 위치 정보 없음 문구와 정상 카드가 동시에 있는 좌표 없는 검색.
- 더보기 버튼 소멸을 끝으로 오인하지 않는 동작.
- 자연순위 20개 및 그 앞의 광고 보존, 20개 미만 비종결 목록의 `PARTIAL`, 명시적으로 종결된 짧은 목록.
- 목표 깊이에 도달해도 파싱 누락이 있으면 `PARTIAL` 처리.
- 자사 매장이 발견된 짧은 비종결 목록도 재수집.

관련 전체 테스트 472개 통과. 이번 작업과 무관한 기존 미추적 육수당 분석 SQL 테스트 5개 파일은 실행 범위에서 제외했다.

DDL 변경, 추가 DB 적재, 커밋 및 push는 수행하지 않았다.
