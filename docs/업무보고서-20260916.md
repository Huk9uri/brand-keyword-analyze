## 2. 키워드 분석 성과 및 자동화 운영 검증

### 실행 범위

기존 파이프라인의 다음 동작을 실제 운영 환경에서 검증하고 있다.

1. 실행일 기준 직전 30일 POS 매출 조회 — 당일 제외
2. 기존 메뉴→키워드 연결 목록으로 매장별 판매량·매출액 합산
3. 판매 키워드 중복 제거 후 검색량 조회·저장, 유효 자료 재사용
4. 매장×키워드 순위 조사 목록 생성
5. 누락·만료 순위 수집 및 DB 저장
6. 판매 확인 및 상위 20위 미노출 후보를 검색량순으로 정리
7. 매장별 결과와 이전 실행 대비 변경 사항 저장

별도 자동화 운영 검증의 POS 조회 기간은 **2026-08-17~2026-09-15**다. 아래 인사이트 보고서는 검증된 **2026년 8월 POS 추출본**을 재사용한 분석이므로 기간과 대상 분모를 구분한다. 검색 요청 간격은 **15초**, 재시도 대기는 **60초·120초**를 유지했다. Place ID 없는 매장 제외, 미연결 메뉴 검토 기록, 수집 실패·불확실한 검색량 보류 등 기존 기준을 유지한다.

### 주요 분석 결과

- **냉면·만두로 확장 후보 범위가 넓어졌다.** 냉면은 판매 매장 114곳 중 98곳, 만두는 130곳 중 101곳이 상위 20위 미노출이다.

- **메뉴의 검색 표현에 따라 노출 차이가 크다.** 갈비탕은 판매 확인 127곳 모두 상위 20위에 있으나, 왕갈비탕은 107곳이 미노출이다. 기존 메뉴의 검색 표현 보완 과제로 검토한다.

- **떡국·황태해장국은 메뉴 적합성 확인이 필요하다.** POS 메뉴명인 떡국설렁탕·사골황태탕이 해당 검색어의 고객 기대와 맞는지 확인한 뒤 시험한다.

검색량은 전국 월간 지표이며 지역 수요·방문·매출 효과를 의미하지 않는다. 미노출은 매장 좌표 기준 모바일 플레이스 광고 제외 상위 20위 밖이라는 뜻이다. POS 수량 30개는 보조 검토 기준이며 성과를 보장하는 기준은 아니다.

## 3. LLM 요약 및 모델 비교

계산과 후보 판정은 코드가 수행하고, LLM은 확정된 근거를 바탕으로 해석·제안을 작성하도록 구성했다.

- 별도 자동화 분석 결과 3,547건을 근거 61개, 약 5,400자의 요약 입력으로 구성했다. 위 8월 POS 기반 인사이트 분석 2,729건과는 분석 범위가 다르다. 문자 수를 토큰 수로 간주하지 않는다.
- 근거 ID와 인용 문장을 대조하고, 해석 영역의 새로운 숫자 기재를 제한한다.
- 분석 보류 상태와 POS 품질 정보를 입력에 포함한다.
- 전국 검색량을 지역 수요나 매출 증가로 단정하지 않도록 지시한다.
- 동일 입력·모델의 정상 요약을 재사용하고 응답 ID·사용 토큰을 기록한다.
- 자동 근거 검증과 별개로 해석의 타당성·한국어 품질은 실제 출력 검토가 필요하다.

비교 후보는 GPT-4.1 mini, GPT-5 mini, GPT-5.6 Luna다. **최신 모델이라는 이유로 선택하지 않고**, 사실 정확성·보류 상태 보존·한국어 품질을 통과한 모델 가운데 실제 토큰 비용과 응답 시간을 비교한다. API 실측 및 최종 모델 선정은 아직 완료하지 않았다.
