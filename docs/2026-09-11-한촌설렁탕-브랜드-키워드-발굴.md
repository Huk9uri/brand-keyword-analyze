## 1. 결론

**메뉴 확장에서는 갈비탕·도가니탕, 음식 분류 확장에서는 국밥, 이용 목적 확장에서는 혼밥·보양식·해장을 우선 검토한다.** 이는 브랜드 조사 우선순위이며, 전 매장 일괄 등록안이나 성과가 검증된 추천은 아니다.

매장별 맞춤 추천과 스마트플레이스 유입 성과 검증은 후속 과제로 분리했다. 이번에는 지역명이나 특정 매장 순위로 브랜드 전체의 가능성을 판단하지 않고, 기존 메뉴 근거·리뷰 문맥·검색 수요를 비교했다. 브랜드 후보를 등록 한도 5개에 맞춰 자르지 않았다.

## 2. 조사 범위와 자료

- 기존 범용 조사 자료와 리뷰 추출 표현에서 메뉴·음식 분류·식사 목적·서비스·음식 특성 대표 표현 22개를 선정해 최신 검색량을 조회했다. 전체 후보 전수 검토를 완료한 것은 아니다.
- 2026-09-11 네이버 검색광고 도구의 월간 PC·모바일 합산 검색량을 수집했다. 정확값 19개, 구간값 3개이며 DB 원응답과 저장값을 대조했다.
- 검색량은 브랜드 유입 수나 식당 방문 수가 아니다. 지역·매장별 수요도 아니며 후보 간 수요가 겹칠 수 있어 합산하지 않는다.
- 기존 승인 공통 메뉴 자료에는 설렁탕·왕갈비탕·얼큰설렁탕·도가니탕·소머리곰탕이 포함돼 있다. 이는 현재 전 매장 판매 여부를 새로 확인했다는 뜻은 아니다.
- [공식 메뉴 안내](https://hanchon.kr/new/html/menu_2.html)의 검색엔진 색인에서 왕갈비탕·도가니 메뉴 설명을 추가 확인했다. 페이지 직접 열기는 502 오류로 본문 최신 확인에 실패했으므로, 신규 메뉴 전체를 확인했다고 주장하지 않는다.

2. 유사한 메뉴명은 검색어별 자료를 보존하되, 같은 역할의 표현을 여러 개 선택해 신규 경로 수를 부풀리지 않는다.

4. 신규 유입 증가를 입증한 결과로 보고하지 않는다. 현재 확인한 것은 검색 수요와 관련 근거이며, 스마트플레이스 기반 적용 전후 검증은 후속 과제다.
