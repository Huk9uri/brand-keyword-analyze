# 매장별 5개 추천 · DB 저장 · 종합 요약

## 확정 동작

기본 모델은 Luna, 추론은 none이다. 추천 가능한 키워드가 5개 이상이면 정확히 5개, 그보다 적으면 가능한 수만 추천하도록 프롬프트와 코드 검증을 함께 변경했다. 소고기미역국은 HMR 제외 정책을 유지한다. 판매·검색량·순위 원본은 변경하지 않는다.

매장별 응답은 구조 및 근거 검증 후 저장한다. 정상 결과는 동일 입력·프롬프트·모델의 재실행에서 재사용한다. 실패는 정상 저장하지 않고 다음 실행에서 재시도한다. 원문 응답을 검증 전에 파일에 저장하여 DB 장애 후에도 API를 재호출하지 않고 복구할 수 있다. 검증 실패·미완료 응답은 invalid-response 파일로 보존하여 정상 캐시로 사용하지 않는다.

## DB

파일은 분석 폴더의 상위 디렉터리에 있는 `llm-results.sqlite3`다. 현재 실행 경로는 `outputs/llm-results.sqlite3`다. 영업 원본 DB를 변경하지 않는 로컬 SQLite이며 관리자 화면과의 API 연결은 별도 작업이다.

- runs: 원자료·프롬프트 지문 기반 실행 ID, 원본 경로, 상태·진행 내역
- summaries: 실행·매장별 입력, 검증된 추천 JSON, 보고서, 응답 ID·토큰·추정 비용을 포함한 영수증
- events: 매장별 성공·실패, 종합 요약 실패 기록. 비밀값이나 외부 오류 본문은 기록하지 않는다.
- overviews: 실행별 코드 집계, 종합 LLM 응답, 영수증, 보고서

원문 응답은 해당 매장 폴더의 api-response 파일로 보존한다. 실패 원문도 invalid-response 파일에서 확인할 수 있다. 원문 파일까지 백업해야 완전한 복구가 가능하다. SQLite는 트랜잭션·WAL 모드로 저장하며 실행별 기존 기록을 분리한다.

## 집계 및 종합 요약

모든 대상 매장이 정상 저장된 뒤 DB에서 결과를 읽어 키워드별 추천 매장 수·매장 목록·우선순위와 원자료 검색량을 집계한다. 전국 검색량을 매장 수만큼 더하지 않는다. 서로 다른 관측값이 있으면 단일 검색량 대신 관측값 목록을 표시한다. 여러 키워드에 중복 연결된 메뉴 매출도 합산하지 않는다.

종합 입력에는 코드 집계와 매장별 핵심 추천·확인 사항, POS 공백·미연결 메뉴·보류 정보를 전달한다. 전체 보고서 전문을 반복 전달하지 않는다. 종합 응답은 한 번 호출하고, 근거 키워드의 존재·중복·HMR 제외를 검증한다. 설명의 모든 의미를 자동 검증하는 것은 아니다.

`aggregate.json`은 집계 원본, `overview.json`은 종합 해석, `summary.md`는 코드 집계와 해석을 합친 메일 본문용 보고서다. `store-reports.md`는 매장별 상세 보고서다. 기존 발송 경로는 종합 본문과 상세 첨부를 사용하되, 이번 실행 명령에는 메일 발송 옵션을 넣지 않는다.

## 실행 및 재개

```powershell
.\.venv\Scripts\python.exe -m scripts.menu_keyword_pipeline.delivery_cli --output outputs/menu-keywords-20260917-scheduled --workers 3
```

기본은 한 매장씩이며 `--workers`는 1~4를 지원한다. 이번 전량 실행은 3개 동시 호출이다. 매장별 API 실행과 파일은 독립적이고 DB 저장·진행 기록은 메인 실행 흐름에서 직렬로 처리한다. 동일 명령으로 재실행하면 정상 결과를 재사용한다. 종합 단계만 실패했으면 매장 API를 다시 호출하지 않고 종합 단계를 재시도한다.

분석 폴더별 잠금이 있어 중복 실행을 차단한다. 강제 종료 뒤 잠금이 남으면 프로세스가 종료됐는지 확인한 뒤 해제한다. 응답 파일 저장 전 강제 종료 시 해당 호출은 재실행 비용이 발생할 수 있다. 새 분석 폴더 간 캐시 공유는 구현하지 않았다.

## 검증

5개 추천 개수 검증, HMR 제외, 매장별 재개·캐시, 부분 실패 발송 차단, 키워드별 전국 검색량 비합산, 종합 DB 장애 후 유료 재호출 없는 복구를 포함해 관련 테스트 27개 통과했다. 실제 실행 결과는 별도 실행 보고서에서 확인한다.

실제 실행 중 발견한 Windows 파일 교체 오류의 제한 재시도와 추천 매장 수 최다 비교 오류 검증을 추가해 최종 테스트는 29개다. 131개 매장·651개 추천·종합 결과가 DB에 저장됐다. 최종 종합 주의사항은 코드에서 작성하며, 원래 LLM 주의사항은 별도 모델 출력 파일로 보존한다. 실제 실행 보고서는 `outputs/menu-keywords-20260917-scheduled/llm-execution-report.md`에 기록했다.
