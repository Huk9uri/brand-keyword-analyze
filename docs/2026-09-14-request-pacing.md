# 전체 매장 순위 수집 요청 간격

전체 매장 수집에 사용되는 `keyword_evaluation.collection.collect_ranks`에서
검색 전 15초 대기와 일반 오류 재시도 대기 60초·120초를 설정한다.
처리 시간 외에 추가되는 대기이며, 배치 첫 요청에도 적용한다.
페이지 내부 상태 확인·스크롤 간격은 기존대로 유지한다.

접근 제한 안내는 기존 보안 확인 중단 경로로 분류하여 재시도하지 않고
증거 저장 후 실행을 중단한다. 요청 간격으로 제한 해제를 보장하지 않는다.
공용 수집기 기본값은 기존 호출과의 호환성을 위해 0이며, 현재 전체 매장
수집 경로는 명시적으로 15초·60초 설정을 전달한다.

사용자 요청으로 30초에서 15초로 단축했다. 기존 실행을 종료한 뒤 DB에
저장된 유효 결과를 재사용하여 새 출력 경로에서 재개한다.
