# 육수당 배달팁 경쟁 분석 로직

## 1. 분석 목적

육수당 각 매장의 실제 배달 주문 데이터를 기준으로 주변 경쟁점의 배달팁 수준을 비교하여, 매장별 배달팁 경쟁력을 진단하는 것이 목적이다.

단순히 특정 주문금액 한 건만 비교하지 않고, 육수당 고객이 실제로 주문한 금액대와 주문 빈도를 반영해 경쟁점의 대표 배달팁을 산출한다.

## 2. 분석 대상

- 브랜드: 육수당
- ERP 기준 DB: `SEIERP_HD`
- 자사 매장: 플랫폼에서 운영 중인 육수당 매장
- 경쟁점: 각 육수당 매장을 기준으로 배달 플랫폼에서 수집된 주변 경쟁 매장
- 분석 플랫폼: 배달의민족, 쿠팡이츠
- 최종 전 매장 시트의 핵심 비교 플랫폼: 배달의민족

## 3. 매장 및 경쟁점 관계

데이터에서 `seed_shop_number`는 경쟁 분석의 기준이 되는 육수당 매장을 의미하고, `shop_number`는 해당 육수당 매장 주변에서 수집된 개별 경쟁점을 의미한다.

따라서 하나의 육수당 매장에는 여러 경쟁점이 연결되는 1:N 구조가 된다.

- `seed_shop_number`: 기준 육수당 매장
- `seed_shop_name`: 기준 육수당 매장명
- `shop_number`: 경쟁점의 플랫폼 매장번호
- 동일한 `shop_number`의 여러 행: 한 경쟁점의 주문금액 구간별 배달팁 정책

`shop_number`가 `seed_shop_number`와 동일한 경우는 육수당 자기 매장이므로 경쟁점 집계에서 제외한다.

## 4. 분석 기간

### 실제 주문 데이터

최근 13개 완료 주의 배달의민족 주문을 사용한다. 분석 시점에 진행 중인 주는 제외하여 기간별 집계 기준을 동일하게 유지한다.

### 경쟁점 데이터

경쟁점 배달팁은 수집된 데이터 중 가장 최근 스냅샷을 사용한다. 이를 통해 과거 정책이 섞이지 않도록 하고 현재 시점의 경쟁 환경을 비교한다.

## 5. 대표 주문금액 설정

한촌설렁탕 분석에서 사용한 2만5천원 기준을 그대로 적용하지 않고, 육수당의 실제 주문 데이터를 별도로 확인하여 대표 주문금액을 설정했다.

육수당 완료 주문의 주요 분포는 다음과 같다.

- 전체 완료 주문: 78,558건
- 주문 발생 매장: 76개
- 주문금액 가중평균: 약 20,212원
- 매장별 평균 주문금액의 중앙값: 약 20,943원
- 개별 주문금액 중앙값: 16,000원
- 개별 주문금액 상위 25% 경계: 24,500원

이를 바탕으로 대표 기준을 약 2만원으로 설정하고, 실제 비교에는 `15,000원 이상 25,000원 미만` 주문을 사용한다.

## 6. 자사 배달팁 산출

운영 완료된 배달 주문을 대상으로 매장별 다음 지표를 집계한다.

- 완료 주문 건수
- 평균 주문금액
- 평균 배달팁
- 배달팁 중앙값
- 배달팁 기록률
- 무료배달 비율

배달팁 기록률은 전체 완료 주문 중 배달팁 값이 존재하는 주문의 비율이다. 무료배달 비율은 배달팁이 기록된 주문 중 배달팁이 0원인 주문의 비율이다.

대표 주문금액 구간의 배달팁 중앙값은 15,000원 이상 25,000원 미만인 실제 주문만을 대상으로 별도 산출한다.

## 7. 경쟁점 배달팁 파싱

경쟁점 배달팁은 주문금액 조건과 배달비가 문자 형태로 수집되므로, 비교 전에 금액 구간과 배달비를 숫자로 변환한다.

### 지원하는 주문금액 조건

#### 하한 개방형

예: `15,000원 이상`

- 최소 주문금액: 15,000원
- 최대 주문금액: 없음
- 15,000원 이상의 주문에 해당 배달팁 적용

#### 범위형

예: `10,000~30,000원 미만`

- 최소 주문금액: 10,000원
- 최대 주문금액: 30,000원
- 10,000원 이상 30,000원 미만의 주문에 해당 배달팁 적용

초기 파싱 실패 행은 DB에 데이터가 없거나 NULL인 것이 아니라, 대부분 범위형 주문금액 조건을 기존 규칙이 해석하지 못해 발생한 것이다. 범위형 규칙을 추가하여 최종 분석에 반영했다.

## 8. 동일 경쟁점의 여러 배달팁 행 처리

동일한 경쟁점에 주문금액 구간이 여러 개 존재하는 경우 각 행을 평균하거나 하나만 선택하지 않는다. 여러 행을 하나의 배달팁 정책표로 결합한다.

예를 들어 동일한 경쟁점에 다음 조건이 존재할 수 있다.

- 5,000원 이상 40,000원 미만: 3,000원
- 40,000원 이상 50,000원 미만: 2,000원

이 경우 주문금액이 20,000원이면 3,000원을 적용하고, 45,000원이면 2,000원을 적용한다.

즉, 경쟁점별 배달팁을 1개의 고정값으로 만드는 것이 아니라 주문금액에 따라 올바른 배달팁을 반환하는 하나의 요금 스케줄로 통합한다.

## 9. 실제 주문금액 기반 경쟁점 배달팁 산출

경쟁점의 대표 배달팁은 다음 순서로 계산한다.

1. 육수당 매장의 15,000원 이상 25,000원 미만 실제 주문을 주문금액별로 집계한다.
2. 각 주문금액이 경쟁점의 어느 배달팁 구간에 포함되는지 확인한다.
3. 해당 주문금액에 적용되는 경쟁점 배달팁을 결정한다.
4. 육수당에서 해당 주문금액이 실제 발생한 횟수를 가중치로 적용한다.
5. 가중된 배달팁 분포의 중앙값을 경쟁점 대표 배달팁으로 산출한다.
6. 육수당 매장에 연결된 경쟁점들의 결과를 배달유형별로 다시 집계한다.

이 방식은 임의의 단일 주문금액만 적용하는 것보다 육수당 고객의 실제 주문 패턴을 더 잘 반영한다.

## 10. 배달유형 구분

경쟁점 배달팁은 다음 유형을 구분하여 산출한다.

- 가게배달
- 알뜰배달
- 한집배달

서로 다른 배달유형의 배달팁을 하나로 평균하지 않고 유형별 경쟁점 중앙값을 제공한다.

## 11. 중앙값 사용 이유

경쟁점 배달팁의 대표값은 평균보다 중앙값을 우선 사용한다.

일부 경쟁점의 비정상적으로 높거나 낮은 배달팁이 평균을 크게 왜곡할 수 있기 때문이다. 중앙값을 사용하면 일반적인 경쟁점 수준을 보다 안정적으로 표현할 수 있다.

## 12. 예외 및 품질관리 기준

### 적용 가능한 구간 없음

특정 주문금액에 해당하는 경쟁점 배달팁 구간이 없으면 `NO_APPLICABLE_RANGE`로 구분한다. 이 값을 임의로 0원으로 처리하지 않는다.

### 중복 구간

한 주문금액이 동일 경쟁점의 두 개 이상 구간에 동시에 포함되는 경우를 검사한다.

- 중복된 행의 배달팁이 모두 같으면 동일 정책의 중복 수집으로 보고 정상 처리한다.
- 중복된 행의 배달팁이 서로 다르면 `AMBIGUOUS_OVERLAP`으로 구분하고 임의의 값을 선택하지 않는다.

### 파싱 실패

주문금액 조건이나 배달비를 해석할 수 없는 경우 원문을 보존하고 실패 상태를 별도로 기록한다. 파싱 실패값을 무료배달로 간주하지 않는다.

### 경쟁점 표본 수

매장별 경쟁점 수를 함께 제공하여 중앙값의 신뢰도를 판단할 수 있도록 한다. 경쟁점 표본이 적거나 없는 매장은 결과 해석 시 주의가 필요하다.

## 13. 매장 매핑 해석

ERP 육수당 매장과 배달 플랫폼 매장번호를 연결하여 분석한다.

플랫폼 매핑에서 누락된 매장번호 수를 실제 미분석 육수당 점포 수와 동일하게 해석하면 안 된다. 하나의 물리 매장이 여러 플랫폼 매장번호를 가질 수 있고, 가상브랜드나 중복 등록이 포함될 수 있기 때문이다.

따라서 매핑 품질은 다음 단계를 구분해 판단한다.

- 플랫폼 매장번호 기준 누락 건수
- 중복 및 가상브랜드 제거 후 물리 매장 기준 누락 수
- 실제 주문이 존재하지만 매핑되지 않은 매장 수
- 분석 결과 시트에 포함된 운영 매장 수

## 14. 최종 산출 항목

전 매장 분석 시트에는 매장별로 다음 정보를 제공한다.

- 육수당 매장명
- 실제 주문 건수
- 실제 평균 주문금액
- 실제 평균 및 중앙 배달팁
- 배달팁 기록률
- 무료배달 비율
- 2만원 대표 구간 주문 표본 수
- 2만원 대표 구간 자사 배달팁 중앙값
- 가게배달 경쟁점 배달팁 중앙값
- 알뜰배달 경쟁점 배달팁 중앙값
- 한집배달 경쟁점 배달팁 중앙값
- 경쟁력 진단 및 데이터 참고사항

## 15. 결과 해석 시 유의사항

- 경쟁점 배달팁은 최신 수집 시점의 정책이며 플랫폼 정책 변경에 따라 달라질 수 있다.
- 실제 자사 배달팁은 최근 13개 완료 주의 주문 결과이고 경쟁점 데이터는 최신 스냅샷이므로 기준 시점이 완전히 동일하지는 않다.
- 쿠폰, 멤버십, 프로모션, 고객별 혜택 등 수집 데이터에 명확히 포함되지 않은 요소는 결과에 반영되지 않을 수 있다.
- 경쟁점 표본이 적은 매장은 중앙값 변동성이 클 수 있으므로 표본 수와 함께 해석해야 한다.
- 분석 결과는 배달팁 정책 검토를 위한 비교 지표이며, 매출·수익성·상권 특성과 함께 종합적으로 판단해야 한다.
