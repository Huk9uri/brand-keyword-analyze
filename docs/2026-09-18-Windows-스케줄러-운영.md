# Windows 작업 스케줄러 운영

- 작업 이름: `BrandAnalyze-MenuKeywords-Daily`
- 실행 시간: 매일 한국 시간 오전 9시
- 실행 파일: `C:\workspace\brand_analyze\run-menu-keywords.bat`
- 현재 사용자 로그인 상태에서 실행한다. PC가 켜져 있고 사용자가 로그인되어 있어야 한다. Codex 대화나 앱을 통한 실행은 필요하지 않다.
- 놓친 실행은 사용 가능한 시점에 실행하도록 설정했다. 중복 인스턴스는 시작하지 않으며, 오래 걸리는 수집을 시간 제한으로 종료하지 않는다.
- 수집 → 분석 → LLM 요약 → Gmail 발송을 수행한다. 기존 당일 완료 검사와 발송 중복 방지를 유지한다.
- 로그: `outputs/scheduler-logs/pipeline.log`
- 단계별 상태: `outputs/scheduled-menu-keywords/operations.json` 및 해당 실행 폴더의 상태 파일.
- 재등록: `powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/register-menu-keywords-task.ps1`
- 실행 연결만 검사: `run-menu-keywords.bat --check` (수집·LLM·메일 호출 없음).
- 수동 실제 실행: `run-menu-keywords.bat` (수집·유료 호출·발송 가능).
- 재부팅 이후 잠금 파일이 남아 있으면 실제 실행 프로세스 유무를 확인한 뒤 복구한다. 무조건 잠금 파일을 삭제하지 않는다.
- 기존 POS 조회 OperationalError는 스케줄러 전환으로 해결되지 않는다. 다음 실행 전 원인 진단이 필요하다.
- HTML 메일 수신 검증 및 메뉴 검토 문구의 자동 생성 코드 개선은 별도 미완료 사항이다.
